#  Testes Manuais

##  Descrição
Este repositório contém a documentação de testes manuais realizados em diferentes sistemas e projetos.  
O objetivo é validar funcionalidades, identificar falhas e garantir a qualidade das aplicações.

---

##  Objetivo
- Verificar o funcionamento das funcionalidades
- Identificar bugs e inconsistências
- Garantir uma boa experiência do usuário
