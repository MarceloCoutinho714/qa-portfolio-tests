#  Evidências de Testes Manuais

Este diretório contém evidências coletadas durante a execução de testes manuais realizados em diferentes funcionalidades do sistema.

##  Objetivo
Registrar provas visuais da execução dos testes, auxiliando na validação dos cenários testados e na documentação de possíveis falhas.

##  Conteúdo
As evidências podem incluir:

-  Capturas de tela (screenshots)
-  Logs ou mensagens de erro relevantes

##  Tipos de Testes
As evidências estão associadas a diferentes tipos de testes, como:

- Testes funcionais
- Testes de fluxo principal
- Testes de cenários alternativos
- Testes negativos

## Organização
Os arquivos estão organizados por:

- Funcionalidade (ex: Login, Cadastro, Carrinho)
- Tipo de cenário testado
- ID do caso de teste (quando aplicável)

##  Observações
- Cada evidência corresponde a um passo ou resultado esperado de um caso de teste.
- Os nomes dos arquivos seguem um padrão para facilitar identificação e rastreabilidade.
