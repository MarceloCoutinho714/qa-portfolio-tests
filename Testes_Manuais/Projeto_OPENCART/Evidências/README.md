#  Evidências dos Testes

##  Descrição
Esta pasta contém as evidências coletadas durante a execução dos testes manuais do projeto.

As evidências incluem capturas de tela que comprovam os resultados obtidos durante os testes, tanto para cenários de sucesso quanto de erro.

---

##  Organização

As evidências estão organizadas por Test Case (TC), onde cada pasta representa um teste específico:

evidencias/<br>
 ├── TC01_Login/ <br>
 ├── TC02_Cadastro/<br>
 ├── TC03_Carrinho/<br>
 └── TC04_Busca/<br>
