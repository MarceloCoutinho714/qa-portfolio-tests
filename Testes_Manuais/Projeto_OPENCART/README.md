#  Testes Manuais - Projeto E-commerce (OpenCart)

##  Descrição

Este repositório contém a documentação de testes manuais realizados em um sistema de e-commerce baseado no OpenCart.  
O objetivo é validar os principais fluxos do usuário, garantindo que as funcionalidades críticas estejam funcionando corretamente.

---

##  Objetivo dos Testes

* Validar o funcionamento das funcionalidades principais do sistema  
* Identificar possíveis falhas e inconsistências  
* Garantir uma boa experiência para o usuário final  

---

##  Escopo dos Testes

Os testes foram realizados nos seguintes módulos:

###  Login

* Login com credenciais válidas  
* Login com credenciais inválidas  
* Validação de mensagens de erro  

###  Cadastro

* Cadastro de novo usuário  
* Validação de campos obrigatórios  
* Tratamento de dados inválidos  

###  Carrinho

* Adição de produtos ao carrinho  
* Remoção de produtos  
* Atualização de quantidade  

###  Busca

* Busca por produtos existentes  
* Busca por produtos inexistentes  
* Validação de resultados exibidos
