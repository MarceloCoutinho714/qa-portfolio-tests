#  Testes de API

##  Descrição
Esta pasta contém testes de API realizados com foco na validação funcional, integridade dos dados e comportamento dos endpoints.

Os testes simulam cenários reais de consumo de APIs, garantindo que os serviços estejam respondendo corretamente conforme esperado.

---

##  Objetivo
- Validar endpoints da API  
- Verificar respostas (status code, body, headers)  
- Garantir integridade e consistência dos dados  
- Identificar falhas e comportamentos inesperados  

---

##  Tipos de Testes Realizados

- Testes de status code (200, 201, 400, 401, 404, etc.)  
- Validação de payload (request/response)  
- Testes de autenticação e autorização  
- Testes de regras de negócio  
- Testes de cenários positivos e negativos
